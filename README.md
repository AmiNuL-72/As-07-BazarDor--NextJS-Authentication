# বাজার দর / BazarDor

BazarDor (বাজার দর) is a modern web application designed to help users track and compare the daily market prices of essential commodities in Bangladesh. It provides real-time insights, price trends, and historical data analysis for everyday items like rice, oil, vegetables, and more.

## 🚀 Key Features

1. **Daily Price Tracking & Trends:** Instantly view which products' prices have increased (▲) or decreased (▼) today on the Home Page, along with a scrolling live ticker for quick updates.
2. **Category-Based Filtering & Sorting:** Easily browse products by categories (e.g., চাল, সবজি, মাছ) and sort them by price (Low to High / High to Low) to find the best deals.
3. **Detailed Market Analysis:** View comprehensive product details, including minimum, maximum, and average prices across different markets, complete with a 7-day price history chart.
4. **Secure User Authentication:** Create an account or log in seamlessly using Email/Password, Google, or GitHub (powered by BetterAuth concepts) to access protected market details.
5. **Interactive User Profile:** A personalized dashboard where users can view and update their profile information with real-time UI synchronization.

## 🛠️ Technologies Used

| Technology | Purpose |
| :--- | :--- |
| **Next.js (App Router)** | Core framework for building the UI and handling fast, secure page navigation with Server Components. |
| **Tailwind CSS & DaisyUI** | Utility-first styling and pre-built component library for a responsive, modern, and clean user interface. |
| **TypeScript / JavaScript** | Providing strict type-checking and robust logic implementation across the application. |
| **BetterAuth** | Modern authentication ecosystem supporting secure Email/Password and Social Login flows. |

## 📦 Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
